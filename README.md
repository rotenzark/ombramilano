# Ombra — un bacaro milanese

Sito one-page di **Ombra**, bacaro milanese in apertura. Trilingue IT/EN/FR, statico, senza build.

- `index.html` — tutto il sito (cerca "DA SOSTITUIRE" per i dati da aggiornare: indirizzo, orari, WhatsApp, Instagram)
- `img/` — immagini ottimizzate per il web
- `originali/` — immagini ad alta risoluzione per social e stampa
- `CNAME` — dominio custom per GitHub Pages (www.ombramilano.it)

La "lavagna di oggi" si aggiorna modificando le righe `<li>` nella sezione `#lavagna` di index.html — la data si aggiorna da sola.
